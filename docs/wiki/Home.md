# AI SUMMIT · 비동기 협업 Wiki

OSS기반SW프로그래밍 프로젝트의 시작·개발·문제 해결 지식을 모읍니다.

## 문서 탐색

- [Getting Started](https://github.com/vicircle22/OSS/wiki/Getting-Started): 준비물, 저장소 내려받기, 첫 실행과 확인
- [Development Guide](https://github.com/vicircle22/OSS/wiki/Development-Guide): 구조, Feature 브랜치·커밋·PR, 테스트와 비동기 소통
- [Troubleshooting](https://github.com/vicircle22/OSS/wiki/Troubleshooting): 증상·원인·해결·검증 순서로 문제 해결

세 문서는 서로 연결합니다. 상세 기획·API 초안·분석 상태는 [PRD](https://github.com/vicircle22/OSS/blob/main/docs/AI-SUMMIT-PRD.md), 코드 변경은 [저장소](https://github.com/vicircle22/OSS)에서 확인합니다.

## 현재 구현 범위

브라우저 메모리 기반 인터랙티브 와이어프레임, Python 표준 라이브러리 기반 DORA 수집·보고서, PR 품질 검사가 있습니다. Spring Boot·PostgreSQL·실제 LLM 연결은 기획이며 구현 완료로 표시하지 않습니다.

## 비동기 기록 원칙

질문에는 배경·목적·재현 단계·기대/실제 결과·시도한 방법·응답 희망 시각을 함께 남깁니다. 해결 내용을 문서에 반영하고, 기술 선택은 ADR에 배경과 대안을 기록합니다. 키·토큰·개인정보는 공개 문서에 올리지 않습니다.
